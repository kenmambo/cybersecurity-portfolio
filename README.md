 PORTFOLIO OVERVIEW
------------------------------------------------------------

This portfolio represents the culmination of an intensive 90-day cybersecurity 
foundation program, combining quantitative data science discipline with core 
defensive security operations. Spanning network traffic analysis, Linux 
system telemetry, forensic investigation, threat modeling, and risk-based 
vulnerability triage, these ten artifacts demonstrate a rigorous conceptual 
foundation and practical competence. By applying statistical anomaly detection 
and data pipeline thinking to threat telemetry, this work illustrates the ability 
to analyze complex attack surfaces, apply industry frameworks (MITRE ATT&CK, 
Cyber Kill Chain), and communicate actionable risk insights to technical and 
executive stakeholders alike.


------------------------------------------------------------
 THE TEN ARTIFACTS
------------------------------------------------------------

  1. Personal Security Audit (Day 3)
     A baseline evaluation of individual digital attack surfaces and credential 
     hygiene — demonstrating initial threat awareness and attack surface reduction.

  2. Phishing Email Analysis (Day 15)
     A structured header and payload investigation of malicious email lures — 
     demonstrating social engineering detection, email protocol header analysis, 
     and indicator extraction (IOCs).

  3. Personal Threat Model (Day 20)
     An application of STRIDE methodology to personal and professional assets — 
     demonstrating structured risk classification, threat actor profiling, and 
     mitigation mapping.

  4. Wireshark Traffic Investigation Report (Day 35)
     A packet-level PCAP capture inspection of suspicious network sessions — 
     demonstrating protocol analysis (TCP/IP, DNS, HTTP), packet decoding, and 
     covert beaconing detection.

  5. Maya Network Defence Plan (Day 45)
     A multi-layered architectural defense proposal for a hybrid enterprise network — 
     demonstrating network segmentation, perimeter filtering, and defense-in-depth design.

  6. Linux Investigation Report (Day 56)
     A command-line host telemetry inspection targeting persistence mechanisms and 
     unauthorized process execution — demonstrating Linux system auditing, cron job 
     analysis, and user privilege verification.

  7. Linux Forensics Investigation (Day 65)
     An artifact recovery and timeline reconstruction of a compromised Linux system — 
     demonstrating log parsing, volatile memory artifact extraction, and chronological 
     incident mapping.

  8. Kill Chain Breach Analysis (Day 73)
     A end-to-end breakdown of a complex enterprise breach mapped to the Lockheed Martin 
     Cyber Kill Chain and MITRE ATT&CK — demonstrating attack surface reconstruction and 
     defensive control gap analysis.

  9. Vulnerability Triage Report (Day 80)
     A contextual, risk-based prioritization of system CVEs weighting active exposure 
     and threat intelligence over raw CVSS scores — demonstrating data-driven vulnerability 
     management and risk modeling.

 10. Cybersecurity Foundations Portfolio (Day 90, this piece)
     A master compilation and narrative capstone bringing together 90 days of security 
     engineering telemetry, artifacts, and personal reflection — demonstrating complete 
     program completion and cross-disciplinary proficiency.

------------------------------------------------------------
 PERSONAL STATEMENT
------------------------------------------------------------

Ninety days ago, I set out to bridge the gap between data science and defensive 
cybersecurity, curious about how statistical modeling and data analytics intersect 
with real-time threat telemetry. Coming into this journey, I viewed security primarily 
through the lens of system logs; today, I see it as an interconnected, dynamic 
adversarial ecosystem governed by risk matrices and human decisions.

The turning point in this journey occurred during the Vulnerability Triage and 
Kill Chain Breach Analysis projects. Realizing that a Critical CVSS 9.8 vulnerability 
on an isolated network poses less immediate risk than a Medium CVSS 6.1 flaw on an 
internet-facing server with an active public exploit POC fundamentally transformed how 
I evaluate system threats. Security is not about chasing theoretical zero-risk; it is 
about data-driven prioritization, exposure management, and breaking the attacker's chain.

I am immensely proud of the Linux Forensics Investigation artifact, where raw system 
logs and process traces were reconstructed into an indisputable timeline of events — a 
process that mirrored complex data cleaning and exploratory data analysis (EDA). 

Moving forward, I am combining my statistical and data engineering background with this 
cybersecurity foundation to pursue entry-level SOC Analyst, Threat Intelligence, or 
Security Data Analyst roles. I look forward to leveraging data science to solve the 
"haystack of logs" problem in modern security operations centers.
